**PROJETO**
- Roterização interna de estabelecimentos.

**INFRAESTRUTURA**
- RailWay como provedor de nuvem.
- NestJS no back-end.
- React Native para o app.

**OBSERVAÇÕES IMPORTANTES**
- Planeje com Opus, use Sonnet para explorar repositórios e executar escrita de código afim de economizar token e contexto.

**TAREFA**
- Monte um handoff para fazer um projeto de orientação interna, baseado em redes wifi.
- Quero que o app seja aberto ao publico, para que as proprias pessoas e estabelecimentos possam mapear internamente suas áreas.
- Tambem use Geolocalização para ajudar a mapear os lugares.
- Faça a principio apenas um MVP, onde eu posso salvar um lugar, e ao clicar em salvar ele mapeia os sinais wifis, mac de dispositivos para identificar onde estou.
